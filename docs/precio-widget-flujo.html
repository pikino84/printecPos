Cómo se arma el precio que muestra el widget

Del precio base del catálogo al precio final que ve el cliente del distribuidor. Incluye las reglas de negocio (perfil <100%, visibilidad de precios) y las páginas donde se configura cada valor.

Lo importante: el "descuento" de un distribuidor no viene de un porcentaje de descuento, sino de tener asignado un nivel con menor markup. El nivel Público es el más caro; conforme un distribuidor compra más volumen, sube de nivel y su markup baja, así que paga menos por el mismo producto.

Fórmula completa

precio_widget = ( ( ( base × (1 + printec% ) ) × (1 + nivel_markup% ) ) × (1 − nivel_desc% ) ) × (1 + margen_distribuidor% )

3Reglas de negocio

⚠️ Perfil < 100% → se cobra el nivel Público

Si el distribuidor es Asociado puro y su perfil está incompleto (< 100%), pierde el nivel de distribuidor que tenga asignado y se le cobra el nivel Público (el de entrada, el de mayor markup) hasta que complete su perfil.

  • En cuanto completa su perfil al 100%, recupera automáticamente su nivel y su mejor precio.
  • Asociado mixto y Proveedor están exentos: son socios estratégicos que también proveen producto, así que conservan su nivel aunque el perfil esté incompleto.

👁️ Mostrar u ocultar el precio en el widget

El widget muestra el precio solo si está activado el interruptor "Mostrar precios en el catálogo". Si está apagado, el widget muestra los productos sin precio.

Se activa o desactiva en posprintec.com/partners/{partner}/api-settings.

🧾 El widget muestra el precio sin IVA

El precio que aparece en el widget no incluye IVA. El IVA (16%) se agrega más adelante, en la cotización.

🟰 Productos propios y de proveedores reciben el mismo aumento

Hoy todos los productos pasan por la misma fórmula: tanto los propios de Printec como los de proveedores (DobleVela / Innovation) reciben exactamente los mismos aumentos. No hay un markup distinto por origen del producto.

🧮 Ojo con el simulador de la pantalla de configuración

El "Simulador de Precio" que aparece en posprintec.com/pricing-settings está simplificado: no muestra el Markup del Nivel y deja el descuento y el margen como "variable". Es solo una ayuda visual aproximada; el precio real del widget sí aplica el markup del nivel como se explica en este documento.
